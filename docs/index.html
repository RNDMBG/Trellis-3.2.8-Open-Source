Get the app

  1. Tap Download latest APK above on your phone.
  2. Open the file. Android will ask if you want to install it. Say yes.
  3. If you already have Trellis, install right over it. Your login stays.

First install only: if your phone blocks installs from the browser, allow it once when asked. Builds are signed with the Trellis key, so updates install over each other.

How it was brought back

There is no official Vine source code. What we had was the original Vine 3.2.8 APK from an old phone. That file holds compiled code, not source, so the first step was taking it apart.

We ran it through JADX, a decompiler that turns compiled Android apps back into Java. Out came more than 5,000 files: every screen, the video player, the chat code, the upload code, all of it. It looked like source code, but it did not compile. Not even close.

The hard parts

  • Decompiler junk. JADX invents fake helper methods (bridge and synthetic methods) and mangles generic types like ArrayList<T>. Hundreds of files had to be cleaned by hand and with small scripts before the compiler accepted them.
  • Missing pieces. Some SDKs inside the app (Flurry, old Google Play bits, Crashlytics) are proprietary and cannot ship in a rebuild. We wrote small stand-in classes with the same shape so the app compiles and runs without them.
  • Old Android vs new Android. The app targets Android 6 era APIs and the original ARM32 video libraries. It now builds against a modern SDK with a compatibility layer, plus a 64-bit build flavor so it installs on today's phones.
  • The resource trap. Android refers to every layout, string and icon by number. Those numbers live in a frozen file (C0257R.java). Every time a resource is added, the numbers shift and the whole file has to be regenerated from the build, or the app opens the wrong screens and crashes. We learned that one the hard way.
  • A living server. Vine's old servers are gone, so the app talks to Trellis, a community-run replacement server. Endpoints move and responses differ slightly, and each difference shows up as an empty tab or a stuck spinner that has to be chased down.

All of that is in the open. The full code, the fixes and the build history are in the repo. Nothing hidden.
